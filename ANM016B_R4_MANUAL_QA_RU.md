# ANM-016B R4 — ручной QA

На iPhone preview проверить:

1. Открыть несколько коротких реплик — каждая должна отображаться нормальной строкой/абзацем, не по 1–2 буквы.
2. Найти длинную реплику, которая раньше обрезала нижнюю строку: она должна либо полностью помещаться, либо стать `1/2 → 2/2`.
3. Проверить `Large text` — paging должен увеличиваться, но страницы остаются нормальными фразами.
4. Повернуть устройство и вернуть обратно — после reflow текст остаётся целым.
5. Проверить AUTO на многостраничной реплике.
6. Проверить, что `save.line`/read state меняется только после последней внутренней страницы.
7. Убедиться, что ANM-016C R2 остался визуально исправленным: персонаж уходит за dialogue card, nameplate полностью виден.
