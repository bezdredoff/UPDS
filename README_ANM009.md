# ANM-009 — Четыре полноценных уровня

Самостоятельный mobile-first vertical slice «Детективы класса U»: visual novel × match-3.

## Реализовано

- все 9 VN-сцен и 262 игровые строки ANM-003;
- три ветки `CHOICE_00` с фильтрацией условных реплик;
- 4 разных match-3 уровня 8×8 с заданными бюджетами ходов;
- сбор нескольких цветов, одно- и двухслойные препятствия, падающие сюжетные объекты;
- линейные special-фишки, каскады, проверка допустимого хода и перемешивание тупикового поля;
- готовые риги Мику, Оноэ и Аюки: `base + face overlay`, speaking, blink, idle breathing и Pose B;
- чистые VN-фоны, runtime-фишки, препятствия, улики и SVG UI из ANM-006;
- досье, статусы оправдания, повторы уровней, счётчик попыток и Continue;
- отдельный ключ сохранения `seiran-detectives-anm009-v1`.

## Осознанные заглушки

Портреты Эми, Маю, Кэнтаро и Норихиро пока не произведены. Для них используется единый маркированный fallback-компонент `PORTRAIT PLACEHOLDER`. Заглушки не участвуют в логике сценария, не требуют отсутствующих файлов и безопасны для production build.

## Запуск

```bash
npm install
npm run dev
```

Полная автоматическая проверка:

```bash
npm run check
```

## Ручной критический путь

1. Новая игра → сцена 0.
2. В сцене 1 выбрать A, B или C и дойти до `Начать поиск`.
3. Победить в `M3_00`; убедиться, что `CUE_001` появилась в досье.
4. Пройти `M3_01–M3_03`; повтор уровня не должен возвращать к pre-сцене.
5. Убедиться, что Кэнтаро и Норихиро переходят в закрытые версии.
6. Дойти до финального кадра с проводящей серебристой нитью.

QA-навигация из главного меню позволяет отдельно открыть любую VN-сцену. Она намеренно не выдаёт пропущенные улики.
