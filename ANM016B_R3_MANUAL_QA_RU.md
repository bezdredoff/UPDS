# ANM-016B R3 — Manual QA

Проверять в GitHub Pages `/preview/` после green importer/PR checks.

## Основной сценарий

1. Открыть VN на iPhone.
2. Перейти по нескольким длинным репликам.
3. Убедиться, что последняя строка полностью видна, включая нижние части букв.
4. Если реплика не помещается, должен появиться `1/N`; следующий тап показывает `2/N`, а не следующую authored VN строку.
5. После последней страницы authored VN ID должен перейти дальше как обычно.

## Reflow

- Повернуть устройство и вернуть обратно: текущая реплика должна перепагинироваться без обрезания.
- Переключить Normal/Large text и закрыть CONFIG: страницы должны пересчитаться.
- Проверить 320×568/короткий viewport, если доступен.

## Regression

- ANM-016A staging не изменился.
- ANM-016C R2: нижняя часть персонажа по-прежнему уходит за dialogue card.
- Nameplate полностью виден поверх stage/dialogue seam.
- LOG/SKIP/AUTO/SAVE/LOAD работают.
- `CHOICE_00` не перескакивается.

## Localization readiness

Для будущего языка установить корректный `<html lang="...">`. Browser measurement остаётся source of truth; количество слов/символов вручную подбирать не нужно.
