# ANM-016B R3 — измеряемая пагинация VN

## Проблема

Лимит по количеству слов/символов не гарантирует, что последняя строка физически помещается в dialogue box. Это особенно плохо масштабируется на локализации: русский, немецкий, английский и японский дают разную реальную ширину/высоту текста.

## Решение

В браузере после построения VN-экрана используется реальный `.dialogue-text` viewport. Кандидатный текст временно помещается в тот же элемент с тем же CSS, после чего сравниваются `scrollHeight/clientHeight` и `scrollWidth/clientWidth`. Если текст не помещается, paginator ищет страницы, которые реально влезают.

Порядок границ:
1. целые предложения;
2. locale-aware words через `Intl.Segmenter`;
3. grapheme fallback для языков без пробелов и патологически длинных токенов.

Текущий HTML уже имеет `lang="ru"`; будущая локализация должна менять `lang`, после чего segmenter/hyphenation получают нужную локаль.

## Стабильность narrative/save

Внутренние страницы не создают новых `VNxxxx`. Авторская строка остаётся одной строкой сценария. `readLines` и `save.line` обновляются только после последней внутренней страницы.

## Reflow

Страницы пересчитываются при:
- повторном renderVN;
- смене размера текста;
- resize/orientationchange;
- завершении загрузки шрифтов через `document.fonts.ready`.

## Headless

Если DOM нельзя измерить, остаётся детерминированный ANM-016B R2 budget fallback. Он нужен для Node/Vitest и не является source of truth в реальной игре.
