# ANM-016B — ручной QA на iPhone

1. Открыть VN на обычном 390×844/393×852: короткие реплики остаются одной страницей.
2. На 320×568 (или через более короткий viewport) открыть VN0001: должна быть `1/2`, без внутреннего скролла текста.
3. Первый тап на `1/2` показывает `2/2`, но не переходит на VN0002.
4. Второй тап переводит на VN0002.
5. В CONFIG включить крупный текст: длинные строки должны чаще делиться, но не обрезаться.
6. Проверить AUTO: он перелистывает `1/2 → 2/2 → следующая VN line`.
7. Проверить LOG: authored VN ID остаётся один, внутренних `VN...-page` записей нет.
8. Проверить SKIP на уже прочитанной сцене: он работает по authored lines, а не по внутренним страницам.
9. Перезагрузить страницу/Continue на длинной VN line: campaign progress не повреждён; строка открывается с первой внутренней страницы.
10. Проверить верхний отступ текста под nameplate: первая строка не должна заходить под плашку имени.
