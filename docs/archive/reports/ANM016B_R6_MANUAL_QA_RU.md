# ANM-016B R6 — Manual QA

Проверить в `/preview/` на iPhone:

1. Обычная короткая реплика: до двух строк, без `…`, без обрезки снизу.
2. Реплика ровно на две строки: обе строки полностью видны, включая нижние части букв.
3. Длинная реплика: `1/N`, в конце непоследней страницы виден `…`; следующий тап продолжает ту же `VNxxxx`.
4. Последняя внутренняя страница: без искусственного `…`.
5. Не должно быть страниц из одного слова/1–2 символов в обычном тексте.
6. Проверить несколько длинных реплик подряд и Large Text.
7. Проверить rotate/resize/reload: paging пересчитывается без потери текста.
8. Убедиться, что ANM-016C R2 сохранился: персонаж уходит за dialogue card, nameplate полностью виден поверх сцены.
