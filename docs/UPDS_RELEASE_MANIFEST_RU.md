# UPDS — манифест релиза

UPDS считается выпущенной, когда существует полностью готовая portrait-first PWA-сборка: она устанавливается, запускается, работает offline после подготовки кэша, обновляется без потери сохранений и проходит финальное human-прохождение на целевых телефонах.

В релиз входят полный Story `0–21`, три финала, 22 Match-3 уровня и кампания, RU/BE/EN, девять основных production-персонажей, шесть гостей без placeholder-подачи, проверенная shipped-графика, вычитанные тексты, подтверждённые Match-3 balance/design и минимальный accessibility/touch gate.

В релиз не входят новые механики и сюжет, landscape, дополнительные языки, character animation, Hero Insert/CG-система, уникальные песни, DLC, native stores/Steam и устранение alias-фонов только ради численного показателя.

Оперативный план представлен кластерами и зависимостями в [`release-status.json`](release-status.json). Живой статус публикуется на [UPDS status dashboard](https://bezdredoff.github.io/UPDS/status/). Источник воспроизводимых проблем — [`known-issues.json`](known-issues.json).

Правило: содержательное состояние задачи меняется явно вместе с результатом и evidence. CI, preview, PR и SHA могут подтягиваться автоматически, но не превращают задачу в `accepted` без ручной приёмки.
