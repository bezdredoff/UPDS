# UPDS — манифест релиза

Разработка игры завершена. Текущая цель — публикация через Playgama после упрощения и рефакторинга кодовой базы, переноса в Godot, подключения Playgama SDK и рекламных SDK при необходимости, прохождения проверки площадки и подготовки страницы игры. Финальная приёмка должна учитывать целевые требования Playgama и обратную связь её менеджеров.

Завершённый игровой объём включает полный Story `0–21`, три финала, 22 Match-3 уровня и кампанию, RU/BE/EN, девять основных production-персонажей, шесть гостей без placeholder-подачи, проверенную графику, вычитанные тексты и принятые Match-3 balance/design. Порт должен сохранять этот объём и основные игровые контракты.

В текущую работу не входят новые механики и сюжет, дополнительные языки, character animation, Hero Insert/CG-система, уникальные песни и DLC. Целевая площадка — Playgama; другие площадки рассматриваются после отдельной оценки требований.

Актуальная последовательность работ описана в [`ROADMAP_RU.md`](ROADMAP_RU.md). Исторические релизные задачи и технические отчёты сохраняются для прослеживаемости; они не расширяют текущий объём разработки игры.

Правило: содержательное состояние задачи меняется явно вместе с результатом и evidence. CI, preview, PR и SHA могут подтягиваться автоматически, но не превращают задачу в `accepted` без ручной приёмки.
