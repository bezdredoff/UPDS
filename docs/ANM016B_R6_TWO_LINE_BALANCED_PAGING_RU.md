# ANM-016B R6 — двухстрочная сбалансированная пагинация VN

## Зачем

R5 стабилизировал render-measurement, но фактический viewport визуально вмещал примерно одну строку. R6 делает стандартом две полностью видимые строки и добавляет presentation-правила, чтобы автоматическая локализационная пагинация не создавала некрасивые хвосты.

## Контракт

1. `.dialogue-text` резервирует две строки + padding + safety buffer.
2. `createDialogueRenderedFit()` активируется только если измеренная геометрия действительно допускает примерно две строки.
3. Если вся authored-реплика помещается — она показывается без внутренних страниц.
4. Если не помещается — runtime ищет границу sentence → word → grapheme.
5. На каждой непоследней внутренней странице UI показывает `…`. Это не часть screenplay и не сохраняется в narrative data.
6. При измерении continuation-страницы место под `…` учитывается заранее.
7. Для whitespace-языков продолжение предпочитает минимум 4 слова и не должно опускаться ниже 3 слов, когда это можно обеспечить перераспределением.
8. Для ja/zh/ko используется locale-aware grapheme model.
9. `VNxxxx`, `save.line`, `readLines`, LOG, SKIP и choice checkpoint работают на authored-line уровне.

## Локализация

Пагинация зависит от фактически отрендеренного текста, поэтому немецкая, английская, японская и другие локализации могут получать различное количество внутренних страниц без изменения стабильных narrative IDs.
