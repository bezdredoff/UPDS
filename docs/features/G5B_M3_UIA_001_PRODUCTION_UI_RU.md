# G5b-M3-UIA-001 — production-перенос M3 UI A

Дата: 2026-10-03. Статус: review, локальные проверки пройдены; human/device acceptance pending.
Baseline: `main` / `e48c14472874b72425099f555090b9e6db26d6a5`.

## Результат

- Согласованная кремово-зелёная подача целей, ходов и реплики перенесена из
  локального preview в `src/match3UiA.css`, с отдельным scope `.m3-ui-a`.
- Shared app header сохраняет markup и визуальные правила. Слева — цели,
  справа — отдельная карточка ходов. Описания целей остаются видимыми и переносятся.
  Метаданные этапа остаются в accessibility tree; level ID видим в общем header.
- Фон показывается без общего затемняющего градиента; сетка спокойнее, размеры
  берутся из контракта уровня, а не из демонстрационного поля preview 7×8.
- `.match-playfield` использует доступную область layout-контейнера, не физический
  `screen.height`. Квадратное/прямоугольное соотношение следует данным уровня.
- `.field-bark-slot` находится под полем рядом с `#hint` в общей панели.
  Замена содержимого реплики больше не требует пересоздавать кнопку; live region
  содержит только реплику. Длинный текст можно прокрутить без смещения поля.
- Hint остаётся action-кнопкой с существующим `showObjectiveHint('manual')`,
  телеметрией и подсветкой реальных клеток. Toggle-семантика `aria-pressed` не добавлена.
  `data-hint-active` отражает показанную подсказку; glow/scale применяется только
  к иконке/тексту. Кнопка сохраняет видимый фокус и минимум 44×44 px.
- Reduced motion отключает scale/transition подсказки. Существующие reaction timers,
  tutorial overlay, жесты, окно Help и русские/белорусские/английские ключи сохранены.
