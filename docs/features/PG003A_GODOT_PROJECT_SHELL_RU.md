# PG-003A — создать основу Godot-порта

Статус: подготовлено к проверке.

## Изменение

- В `godot/` создан отдельный Godot project, не затрагивающий существующую web-сборку.
- Зафиксированы portrait viewport 480×854, `canvas_items` scaling и Compatibility renderer.
- Точка входа показывает явно временное состояние порта; игровые экраны в этой задаче не имитируются.
- Добавлена структурная проверка конфигурации и сцены средствами Vitest.

## Следующий этап

Переносить первый завершённый игровой экран отдельно, сверяя его состояния и действия с текущей web-версией. Для runtime smoke check открыть `godot/` в Godot 4.7 stable и запустить main scene. На момент этой задачи Godot editor/bridge недоступен, поэтому проверка движком ещё не выполнена.

## Проверка

Полный `npm.cmd run check` и `npm.cmd run version:check` должны пройти до слияния. Статический тест не заменяет загрузку и запуск проекта в Godot.
