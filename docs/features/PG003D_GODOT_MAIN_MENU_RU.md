# PG-003D — перенести главное меню в Godot

Статус: на проверке.

## Изменение

- Godot открывает первую портированную игровую страницу вместо пустой bootstrap-сцены.
- В сцену перенесены фон комнаты клуба, три портрета и основные кнопки из web-меню.
- Текст меню поддерживает русский, английский и белорусский по языку системы.
- Кнопки публикуют сигналы навигации; подключения Story, Match-3 и Settings добавляются вместе с портированием этих экранов.
- Кнопка Continue выключена, пока не перенесён адаптер сохранений.

## Проверка

`godot/check.ps1` проверяет GDScript, bootstrap и главное меню в Godot 4.7.2.
SceneTree smoke test проверяет ресурсы, локализованный текст, состояние Continue и
сигналы меню. Структурный контракт добавлен в `tests/GodotMainMenu.test.ts`.
