# PG-003L — точная стартовая раскладка M3_00 в Godot

Статус: на проверке.

## Объём

Начальная доска Godot для M3_00 теперь экспортируется из production `Match3Game`
вместе с уровнем. Godot использует эти 63 клетки для открытия и retry. Так native
версия показывает ту же раскладку, что web-версия для уровня с seed `9001`, без
начальных совпадений и с доступным ходом.

Решение учитывает различие между Godot и JavaScript `Array.sort` при генерации
стартовой палитры. Экспортёр остаётся единственным источником раскладки; Vitest
проверяет fixture против web-модели, а Godot smoke — все клетки native-модели.

## Границы и проверки

Этот срез фиксирует только начальное поле M3_00 и его повторяемость при Retry.
Порядок дальнейших seeded значений для refill/reshuffle пока не сравнивается с web;
точная RNG parity для ходов и остальных кампаний остаётся отдельной задачей.

Проверки: `tests/GodotMatch3Parity.test.ts` проверяет exported opening board;
`godot/check.ps1` сравнивает его с native-моделью и проверяет отсутствие стартовых
совпадений и наличие легального хода.
