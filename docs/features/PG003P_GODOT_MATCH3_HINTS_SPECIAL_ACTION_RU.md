# PG-003P — подсказки и прямое использование спецфишек в Godot

## Цель

Перенести оставшиеся интерактивные действия Match-3 модели из TypeScript в Godot, сохраняя поведение движка источником истины до закрытия parity.

## Изменения

- Добавлен `attempt_special_activation(index)`: проверяет состояние/клетку, расходует ровно один ход, разрешает эффекты, обновляет цели и обрабатывает победу, поражение и перемешивание при отсутствии ходов.
- Добавлен `get_hint_move()`: оценивает legal swaps по совпадениям, активным specials и прогрессу collect/blocker/ingredient целей. Подсказка использует прежний lexicographic приоритет цели и тот же стабильный hash tie-break, что TypeScript.
- Match detection разделён на обычные совпадения для выбора/оценки хода и resolution groups, в которые входят 2×2 формы Lead. Это сохраняет создание Lead, но не позволяет квадратам менять рейтинг подсказок.
- Экран M3_00 получил локализованную кнопку подсказки RU/BE/EN и двойное нажатие спецфишки в окне 360 мс.
- Добавлен седьмой TypeScript oracle сценарий для прямой активации. Все семь стартовых состояний также сравнивают точную подсказку (индексы и score); активация дополнительно сверяет moves, цель, результат и полную финальную доску.

## Проверка

- TypeScript fixture генерируется из production `Match3Game` тем же Match-3 exporter.
- `npm run check` проверяет fixture freshness, полный Vitest набор, lint и production build.
- `godot/check.ps1` парсит новые скрипты и исполняет runtime parity smoke на Godot.

## Границы

Godot story gate по-прежнему открывает M3_00. Кампания, выбор следующего уровня и parity reshuffle остаются отдельной задачей. Browser Level Lab остаётся авторским инструментом TypeScript.
