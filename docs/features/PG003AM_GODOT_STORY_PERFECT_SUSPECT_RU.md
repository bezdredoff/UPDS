# PG-003AM — Маршрут «Идеальный подозреваемый» в Godot

Перенести выбранную стратегию C до третьей концовки, используя существующий Match-3 runtime и общий экран исхода.

- `VN_SCENE_43_E21_PRE` (VN0925–VN0944) → `M3_21_CONVENIENT_CASE` / `CUE_022` → `VN_SCENE_44_E21_POST` (VN0945–VN0964).
- Сцены, переход и локализации экспортируются из канонического story graph; ассеты остаются копиями исходных файлов.
- Победа сохраняет прогресс уровня и CUE_022, открывает пост-сцену, а terminal transition показывает `ENDING_C_PERFECT_SUSPECT` на общем локализованном экране.
- Continue восстанавливает позицию; save key/schema не меняются.
- Parity проверяет RU/BE/EN, VN IDs, переход и M3_21/CUE_022. Native smoke проходит gate, win path, экран Ending C и восстановление терминального результата.
