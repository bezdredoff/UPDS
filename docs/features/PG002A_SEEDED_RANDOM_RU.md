# PG-002A — закрепить контракт seeded random sequence

Статус: подготовлено к проверке.

## Изменение

Вынесен алгоритм генерации seeded random stream из `Match3Game.ts` в
`src/engine/SeededRandom.ts`. Match-3 engine вызывает ту же функцию с тем же seed; алгоритм и
порядок потребления значений не менялись.

## Контракт

- Алгоритм имеет идентификатор `UPDS seeded random sequence v1`.
- Входное значение нормализуется к unsigned 32-bit через `seed >>> 0`.
- Выход каждого вызова лежит в диапазоне `[0, 1)`.
- Изменение формулы требует новой версии алгоритма и отдельной проверки влияния на стартовые
  доски и seeded QA fixtures.

Тест фиксирует первые пять значений для seed `9001` и подтверждает повторяемость независимых
потоков. Это даёт будущей Godot-реализации компактный parity contract без смены поведения web-игры.
