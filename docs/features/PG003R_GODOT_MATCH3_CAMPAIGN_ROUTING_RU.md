# PG-003R — отдельная Match-3 кампания в Godot

## Изменения

- Кнопка кампании открывает локализованную доску всех 22 уровней с прогрессом, числом попыток и лучшим результатом.
- Первый уровень доступен сразу; следующий открывается после завершения предыдущего. Пройденные уровни можно запускать повторно.
- Выбранный уровень запускается в общей Godot Match-3 модели с его целями, topology, blockers, ingredients, spawn weights и seeded opening board.
- Экспорт Godot bundle содержит локализованные названия, описания, цели и реплики для каждого уровня на RU/BE/EN.
- Экран доски использует набор тайлов выбранного уровня и показывает blockers и ingredients. Результат standalone-кампании возвращает игрока на доску кампании.
- Standalone Match-3 сохраняет отдельный прогресс и не изменяет сюжетный save. Сюжетный VN gate по-прежнему запускает M3_00 и продолжает в пост-match VN после победы.

## Проверки

- `godot/check.ps1` проверяет локализованный экран кампании, последовательную разблокировку, запуск выбранного уровня и возврат в hub.
- Model smoke проверяет конфигурации всех 22 уровней.
- `npm run check` проверяет parity Godot bundle с каноническими TypeScript данными, lint, тесты и сборку.

## Границы

Уровни пока не связаны с отдельными VN-сценами кампании; сюжетный Godot flow остаётся портированным до доступной сцены post-match. Web-runtime остаётся эталоном правил и контента до завершения parity-проверок Godot пути.
