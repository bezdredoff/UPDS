# PG-003E — настройки языка Godot

Статус: на проверке. Локальный кандидат после merged PR #396.

Кнопка настроек главного меню открывает нативный экран с выбором русского,
белорусского и английского языка. Язык немедленно обновляет настройки и меню;
возврат доступен кнопкой и Escape, с восстановлением фокуса на кнопке настроек.

`player_preferences.gd` хранит язык в `user://player_preferences.cfg`, отдельно
от Story/Match-3 saves. При отсутствии или неправильном значении используется
прежний system-locale fallback. Ошибка записи сохраняет старый выбор и выводит
локализованное сообщение. Игровые save keys/schema не меняются.

Это первый срез настроек: audio controls, previews и haptics ещё не перенесены.
Web PWA install/cache controls не относятся к нативному экрану.
Общий выбор языка будет использоваться следующими портируемыми экранами.

Проверка: `godot/check.ps1` запускает settings smoke test: переход из меню,
все три языка, reload настроек, возврат/повторное открытие, Escape,
некорректный сохранённый тип и ошибка записи. Тест использует отдельный временный
файл и не меняет настройки игрока. Визуальная приёмка остаётся отдельной.

Локальные проверки 2026-10-13: все 7 стадий Godot check, `npm run check:fast`,
16 тестов Godot/contracts/documentation прошли. Через MCP открыт экран,
проверена русская копия; runtime errors = 0. Общая тема кнопок вынесена в
`menu_theme.gd`, настройки и меню имеют различимый keyboard focus.

Версия web/PWA не меняется: изменения runtime ограничены отдельным `godot/`
проектом; npm package и `src/appVersion.ts` относятся к прежнему web build.
