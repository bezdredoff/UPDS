# PG-002D — отделить источник монотонного времени

Статус: подготовлено к проверке.

## Изменение

- `src/contracts/ClockRuntime.ts` задаёт runtime-neutral `now()` в миллисекундах от монотонного,
  произвольного начала отсчёта.
- `BrowserClock` реализует контракт через `performance.now()`; web composition публикует его в
  `RuntimeServices`.
- VN и Match-3 используют один источник для защиты от повторного тапа, распознавания жестов,
  длительности попытки и cooldown реакций.

## Границы

Семантика времени остаётся elapsed time и не зависит от системных часов пользователя. Отложенные
вызовы, анимации и browser timers пока остаются в UI/platform слое и не входят в этот контракт.
Игровые правила, тексты реакций и интервалы не меняются.

## Проверка

Архитектурный тест запрещает прямые `Date.now()` и `performance.now()` в VN/Match-3 controllers.
Полный `npm.cmd run check` и version policy должны пройти до слияния.
