# G5b-M3-RECT-002 — production-пилот поля 7×9 на M3_06

Дата: 2026-10-03. Статус: **active · код-кандидат, human/balance acceptance pending**.
GitHub baseline: `main` / `919271a` (PR #330, #331, #329).

## Цель

Проверить rectangular board foundation и UI A в настоящем сюжетном уровне, прежде чем
переносить конфигурации остальных уровней. Используется M3_06 — уровень из первого
human pass с отмеченной сложностью и визуально синим полем. Это ограниченный пилот,
а не принятие всей кампании 7×9.

## Изменение

- Стабильный ID `M3_06_TEXTILE_WORKSHOP`, story route и seed `9007` сохранены.
- Размер: 9 строк × 7 столбцов, 63 позиции; дырки `3`, `10`, `17` формируют два
  входа по три колонки и общий стол снизу.
- Восемь позиций преград и два ингредиента расставлены по уже подготовленному
  прототипу в `tests/fixtures/match3Rectangle.ts`; fixture теперь возвращает production
  level, поэтому геометрия не хранится в двух местах.
- Цели, target values и лимит `32` хода пока не менялись. Увеличенный путь к нижнему
  краю означает, что баланс этого уровня не принят.
- Для проверки замечания о визуально синем поле `towel` заменён на
  `pantiesHighWaistBlack` в наборе M3_06. Это targeted visual adjustment, не вывод о
  балансе.
- Остальные 21 уровня сохраняют legacy 8×8; массовая переиндексация не выполнялась.

## Что нужно проверить в human pass

На следующем прохождении отдельно записать: помещается ли 7×9 поле в мобильный viewport,
читаются ли крупнее тайлы, понятна ли форма двух входов, видны ли объекты и корректны ли
подсказки рядом с преградами, сколько ходов остаётся при победе/поражении и изменилось ли
ощущение сложности. Текущие E5A/E5B результаты M3_06 получены на прежней 8×8 геометрии
и не считаются доказательством для пилота.

## Приёмка и ограничения

- Rectangular contract и production-пилот проверены автоматическими проверками в
  CI/локально при PR #331/#329. После merge выполнен all-22 auto-audit: 4 400 прогонов
  на baseline `919271a`; результаты в
  `docs/reports/G5B_POST_FEEDBACK_MATCH3_AUTO_AUDIT_2026-10-03.json`.
- Требуется отдельная desktop/mobile проверка именно production route M3_06 и повторный
  human playtest; реальный телефон остаётся главным визуальным gate.
- Не переводить остальные уровни и не менять move budget по одному лишь числу клеток.
- Не менять save schema, Story/VN IDs, campaign keys или остальные level IDs.
