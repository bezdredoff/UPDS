# PG-003B — проверять Godot project shell через движок

Статус: подготовлено к проверке.

## Изменение

- Добавлен `godot/check.ps1`: проверяет путь к Godot, импортирует проект, отдельно парсит bootstrap script и запускает smoke test.
- `godot/tests/port_bootstrap_smoke.gd` загружает сцену, инстанцирует её и проверяет содержимое статусной метки.
- Godot-generated `.uid` файлы сохранены рядом со скриптами; кеш редактора остаётся исключён из Git.

## Проверка

Проверено локально на Godot 4.7.2: все три этапа завершаются с кодом 0, сцена загружается, `_ready()` вызывается, smoke test сообщает об успехе. Полный `npm.cmd run check` остаётся обязательной проверкой web-репозитория.
