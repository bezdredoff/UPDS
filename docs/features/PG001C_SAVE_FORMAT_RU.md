# PG-001C — отделить формат Story save от хранилища

Статус: подготовлено к проверке.

## Изменение

- Нормализация состояния, проверки схемы, декодирование legacy/current saves и формат export bundle перенесены в `src/engine/CampaignSaveFormat.ts`.
- `CampaignStore` сохраняет роль адаптера: чтение/запись через `KeyValueStorage`, recovery backup и побочные эффекты импорта.
- Существующие импорты из `CampaignStore` сохранены через re-export, чтобы не менять consumers этого слоя.
- Добавлены тесты формата без создания хранилища.

## Границы совместимости

Ключ сохранения и schema version не менялись. Нормализация, допустимые поля, legacy import,
отклонение чужих/будущих схем и экспортный формат сохраняются. `CampaignStore` по-прежнему
отвечает за побочные эффекты и сообщения интерфейсу; этот шаг не переносит web diagnostics или
file download flow.
