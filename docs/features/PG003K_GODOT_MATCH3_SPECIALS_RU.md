# PG-003K — специальные фишки Match-3 в Godot

Статус: на проверке. Основано на `origin/main` после PR #402 (`53e5007`).

## Объём переноса

Перенесены существующие правила `src/engine/Match3Rules.ts` в Godot-модель уровня
`M3_00_LOCKER_TUTORIAL`. Игрок создаёт специальные фишки существующими формами:

- четыре в ряд или столбец — `flash-row` / `flash-column`;
- линия из пяти и более — `insight`;
- пересечение линий T/L — `evidence`;
- квадрат 2×2 — `lead`.

Специальная фишка сохраняет базовый тип предмета. Она срабатывает при попадании
в совпадение или при обмене с соседней фишкой. Эффекты каскадируются через другие
специальные фишки. `Lead` очищает крест вокруг себя и выбирает одну удалённую
целевую фишку, если цель уровня ещё не собрана; иначе выбирает первую доступную.
После осыпания пара «предмет + спецфишка» остаётся целой.

Перенесена матрица прямых обменов специальных фишек: Flash+Flash, Flash+Evidence,
Evidence+Evidence, Lead+Flash, Lead+Evidence, Insight+обычная и Insight+специальная.
Остальные пары очищают две выбранные клетки с обычным расширением эффектов.

В интерфейсе тип спецфишки помечен контрастным значком поверх исходного изображения.
Пять production PNG, описанные в visual contract B0A1, не входят в этот срез;
значки являются временным Godot fallback и не меняют арт исходной игры.

## Проверки и границы

`godot/check.ps1` проверяет формы создания, цели всех пяти спецфишек, прямой Flash
комбо, обмен/ход и сохранение состояния фишек при осыпании вместе с остальными
Godot smoke-сценариями. `tests/GodotMatch3SpecialsParity.test.ts` фиксирует связь
перенесённых типов и эффектов с исходным движком.

Точное совпадение seeded раскладки с web-версией, post-win VN начиная с `VN0059`,
прочие Match-3 уровни, production visual pack и проверка на физических устройствах
остаются следующими отдельными задачами. Этот срез переносит готовые правила игры,
а не добавляет игровые механики.
