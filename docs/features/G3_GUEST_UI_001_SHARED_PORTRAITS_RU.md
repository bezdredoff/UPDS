# G3-GUEST-UI-001 — общий VN-портрет для гостей

Дата: 30.09.2026. Статус: локальный кандидат для review, ещё не опубликован.

Пользователь после просмотра production art запросил одинаковую подачу гостей и остальных персонажей.
Раньше гостевой PNG отображался маленькой фигурой внутри декоративной рамки, рядом была карточка
с именем свидетеля. Теперь renderer использует `.portrait` / `.portrait-frame`, общую камеру
`resolveVnPortraitCamera()` (`178% / -78%`) и правую диалоговую позицию. Имя и эмоция находятся в
общем VN dialogue row. Дополнительные рамки, силуэты и testimony identity card удалены.

Это явное изменение presentation-контракта по запросу пользователя. Ассеты и guest tier сохраняются:
6 гостей × 4 PNG, прежние speaker tokens и две эмоции. Исторический ID `guest-testimony-card` сохранён
для совместимости Story/Studio; preset содержит один guest slot и ноль native UI slots.
В Studio он называется «Гостевой портрет». Full-stage семь-assetный контракт не расширяется.

Проверки: локальный `npm run check` завершился успешно (147 файлов, 716 тестов, production build).
Проверены все 18 комбинаций гостя/эмоции в renderer-тесте. В браузере на размере 402×874
проверена реальная реплика Хинаты: лицо, фон, плашка имени, диалог и кнопки видны.

Ручная приёмка: открыть кандидат с `?qa=1`, перейти в сцены 13/19/21/27/29/33, проверить реплики
всех шести гостей. В Studio → Composition → «Гостевой портрет» проверить neutral/serious/smile
на 320×568 и больших телефонных размерах. Реальный iPhone и Mobile WebKit gate ещё не проверены
для этого локального кандидата.
