# PG-003O — общая Godot-модель уровней Match-3

## Цель

Подключить Godot-модель к каноническим данным кампании и перенести основные правила поля, целей и blocker-слоёв. До окончания порта TypeScript-движок остаётся эталоном поведения; fixtures на одинаковых стартовых досках и seed сравнивают реальные ходы обеих реализаций.

## Перенесённые правила

- Godot-модель загружает любой из 22 уровней из общего `campaign_match3_levels.json`; M3_00 остаётся уровнем по умолчанию для текущего story gate.
- Цели collect, clearBlockers, drop и dropGroup учитываются независимо, включая несколько целей на одном уровне и переходы win/loss.
- Типы blocker `locked`, `solid` и `overlay`: hard blocker ограничивает обмен/совпадение и делит вертикальное осыпание; overlay пропускает плитки, но получает урон от совпадения на своей или соседней по стороне клетке.
- Слои blocker повреждаются не более одного раза за каскад; progress засчитывается при снятии последнего слоя.
- Ингредиенты перемещаются при осыпании, достигают нижней активной клетки колонки, снимаются с поля и обновляют одиночные/групповые цели.
- Генерация пополнения применяет заданные spawn weights, а board holes остаются неигровыми клетками и в совпадениях, и при генерации/осыпании.

## Поведенческий parity

`godot/data/match3_parity_cases.json` генерируется тем же exporter из production TypeScript `Match3Game`. Шесть кейсов фиксируют одинаковый seed, стартовое состояние и последовательность ходов для collect, layered blockers, ingredient drop, dropGroup, irregular board holes и overlay blockers. Godot smoke исполняет ходы в нативной модели и сравнивает результат, каскады, прогресс всех целей и полное финальное состояние доски с TypeScript oracle.

Полный check также создаёт Godot-модель для всех 22 уровней и проверяет паритет стартовой доски, blockers/ingredients, отсутствие начальных совпадений и доступность хода.

## Что ещё не завершено

Текущий Godot UI по story gate всё ещё запускает только M3_00. Следующие срезы должны добавить campaign routing/выбор следующего уровня, parity для специальных комбинаций/refill/reshuffle и подсказок, а затем удалить старый M3_00 fixture после перевода экрана на общий bundle. Browser Level Lab остаётся авторским инструментом TypeScript; production-уровни в нём экспортируются из единого источника, а не редактируются независимо в Godot.

## Проверка

- Полный `npm run check`, включая проверку актуальности bundle и parity cases.
- Полный `godot/check.ps1`: GDScript parser, 22 стартовые доски, интеграционные smoke и шесть сравнений игровых ходов с TypeScript oracle.
