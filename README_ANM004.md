# ANM-004 — Narrative Graybox

Запускаемый вертикальный срез аниме VN × match-3 на технической основе Raven Manor.

## Что реализовано

- главное меню, новая игра и продолжение;
- 9 VN-сцен из ANM-003 с исходными line IDs;
- `CHOICE_00` с тремя ветками и последующим схождением;
- 4 интерактивных match-3 graybox-уровня;
- результаты уровней и 4 сюжетные улики;
- досье и экран выбора сцен для быстрой проверки;
- сохранение сцены, строки, выбора и прогресса в `localStorage`;
- финальный клиффхэнгер с серебристой проводящей нитью;
- portrait-first интерфейс 320–430 px.

## Запуск

```bash
npm install
npm run dev
```

Production-проверка: `npm run build`.

## Graybox-ограничения

Фоны и персонажи намеренно представлены постановочными заглушками. Match-3 проверяет переходы, цели, ходы, победу/поражение и возврат в сюжет; финальный баланс и графика относятся к следующим этапам.

Исходный Raven Manor не изменяется. Проект использует отдельный ключ сохранения `seiran-detectives-graybox-v1`.
